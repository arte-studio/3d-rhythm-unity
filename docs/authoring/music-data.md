# 曲の拍・テンポ・区切りの直し方（音楽に詳しい人向け）

曲ごとの「拍・テンポ・小節・区切り（前奏，A メロ…）」は，譜面（ノーツ）と LED 演出の両方の基準になる．
最初は曲の音声を解析して入れた **案** なので，音楽に詳しい人に確かめて直してもらうことを前提にしている．
直すと，ノーツと演出は「何小節目の何拍目」を保ったまま付いてくる（下の「保存すると」）．

新しい曲で拍と小節の頭を最初に決めるときは `beat-finding.md`（解析ツール → AI → 聴き比べ）．

## どこに入っているか

`3d-rhythmgame/Assets/Rhythm/Songs/<曲>/song.json`（譜面エディタで編集する．手で書き換えてもよい）

| 項目 | 中身 |
| --- | --- |
| `tempo` | テンポ表．1 行目の `t`（秒）が 1 小節目の頭．`bpm`，`beatsPerBar`（1 小節の拍数）．途中で変わるなら行を足す（その時刻から新しいテンポ・拍子） |
| `sections` | 曲の区切り．`t`（始まる秒）と `name`（前奏，A メロ…）．次の区切りまで続く |
| `notes` | ノーツ．`t`（秒），`lane`（0 から） |

時刻はすべて「曲時刻」（音声ファイルの `audioStartSec` の位置が 0 秒）．

## 確かめ方

1. Project で曲（例: `Assets/Rhythm/Songs/kodaisai-2025/kodaisai-2025`）をダブルクリックして譜面エディタを開く．
2. **M**（またはツールバーの「メトロノーム」）を入れて再生（Space）する．拍ごとにクリック音，小節の頭は高い音．
3. クリックが曲の拍に合っているか，高い音が小節の頭に来ているか，区切り（波形の上の色の帯）が合っているかを聞く．

## 直し方

| 直したいもの | やり方 |
| --- | --- |
| テンポ・1 小節目・拍子（曲を通して一定） | 譜面エディタの 2 段目の「BPM」「1小節目(秒)」「拍子」に入れる．すぐメトロノームに反映される |
| 叩いて合わせたい | 再生しながら拍に合わせて叩く（小節の 1 拍目は **N**，ほかは **B**）．20〜30 回で合う（`docs/authoring/chart-editor.md`） |
| 途中でテンポ・拍子が変わる | 「テンポ表…」で，変わる小節の頭の時刻に行を足す．「カーソルの位置に行を足す」が便利 |
| 区切りの位置 | 波形の上の区切りの線をドラッグ（スナップが入っていれば拍に合う） |
| 区切りの名前・追加・削除 | 波形の上で右クリック |

## 保存すると（Ctrl+S）

テンポ・1 小節目・拍子を変えていたら，保存のときに聞かれる:

- **全部動かす**: ノーツ・区切り・演出（Timeline のクリップ）を，同じ「小節.拍」に来るように動かす
  （例: 12 小節目の 3 拍目にあったものは，直したあとも 12 小節目の 3 拍目）
- **区切りと演出だけ動かす**: ノーツは秒のまま（音を聞いて置いたノーツは，テンポを直しても音と合ったままにしたい）
- **動かさない**: 全部秒のまま

拍に合わせて置いたもの（スナップや Alt + クリック）は動かし，音を聞いて置いたものは動かさない，が目安．
迷ったら「動かさない」で保存し，メトロノームで聞き比べてから譜面エディタの Ctrl+Z（元に戻す）で戻せる
（保存した song.json は git で前の版に戻せる）．

保存すると，曲の Timeline の一番上の「曲（小節と区切り）」トラックの目印（小節番号と区切りの名前）も作り直される．

## 演出（Timeline）側

- 一番上の「曲（小節と区切り）」トラックに小節の頭と区切りの目印が出る（自動．手で動かさない）．
- 演出のクリップを選ぶと，Inspector の上に「始まり（小節）」「始まり（拍）」「長さ（拍）」が出る．数字を直すとクリップが動く．
- クリップを右クリック →「拍に合わせる（Arte Rhythm）」，または Inspector の「始まりと終わりを近くの拍に合わせる」で拍にそろう．

- テンポ 151.96 BPM，4 拍子，1 小節目 1.435 秒（2026-10-28 確定．下の「拍の決め方」）
- 区切り: 前奏 0.00 / A メロ 14.070 / B メロ 26.705 / サビ1 42.498 / サビ前（デクレッシェンド→クレッシェンド）64.610 / サビ2 67.768 / 最後 80.403（秒）．
  すべて小節の頭（サビ前は 41〜42 小節の 2 小節）
- 決めきれていない点: サビ1 の終わり（51.5 秒でさらに大きくなる），サビ前の長さ
- 拍の決め方: 叩いて取ったテンポ（1.573 秒）は音の立ち上がりより 60〜80ms 早かった（人は少し早めに叩く）．
  この曲は半拍ごとの音がはっきりしていて，解析だけでは表拍と裏拍を決めきれないので，クリックを重ねた音を 2 通り作って聴き比べ，
  拍は耳で，小節の頭（1 拍目）も耳で決めた．新しい線には音の立ち上がりが ±10ms で乗る（`beat-finding.md`）
- 今のノーツは拍の位置に乗っていないものが多い（耳で置いたらしい）
